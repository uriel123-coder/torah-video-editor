# Worked example: Gemara debate

For a debate, establish the shared question first. Use two clean columns for the named positions, with the same typographic weight. Animate the logical point of disagreement across a central divider. A later conclusion card must quote the teacher's conclusion or say `La clase deja la cuestión abierta`.

Never use red/green, upward/downward arrows, applause, or “winner” motion to encode correctness. If one position is accepted according to the teacher, label that as the teacher's stated conclusion and preserve the source record.
